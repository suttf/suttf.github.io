# Suttf Widget Library V4

## Design direction
Dark information-dense interface designed to sit beside native Notion blocks without looking like a separate themed website.

- Dark neutral surfaces
- Compact rounded cards
- Dense information hierarchy
- Small functional icons
- Restrained accent color
- System UI typography
- No gradients, decorative textures, or forced "academic" ornament

## Independent widgets

Each widget is a standalone page:

`/widgets/clock/`
`/widgets/date/`
`/widgets/countdown/`
`/widgets/stopwatch/`
`/widgets/study-time/`
`/widgets/deep-work/`
`/widgets/daily-progress/`
`/widgets/weekly-study/`

## Theme

Edit `shared/theme.css` to change the global visual language.

## Data

`shared/config.js` currently contains demo study data. The next phase can replace these values with live Notion API data.
